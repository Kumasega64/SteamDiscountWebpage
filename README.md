
🎮 Steam Deals Finder

I am a sucker for a deal and steam is a storefront with deal 24/7 but with so many deals it hard to pinpoint which one you want to purchase. I wanted to create A simple web app that recommends Steam game that are currently on sale using the CheapShark API (https://www.cheapshark.com). Users can search for the best deals based on price range, Metacritic score, and review count. 

🧠 About

This project lets users fetch Steam sale recommendations dynamically from the CheapShark API. It filters deals by:

- Lowest price
- Highest price
- Minimum Metacritic score
- Minimum number of reviews


Returning a clean list of game recomendations for the user to chose form .
